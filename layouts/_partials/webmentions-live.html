{{/* Live webmention counts, fetched in the browser. Complements the build-time data in data/webmentions/ rather than replacing it. The two answer different questions: build-time (webmentions.html) — everything as of the last cron pull. Works with JS off, is in the HTML source, is archived in git. Up to 24h stale. runtime (this file) — everything webmention.io knows right now, including mentions that arrived minutes ago. Costs a request per page view and shows nothing to a reader with JS off. So this renders *in addition*, and only says something when it finds MORE than the page already shows — otherwise every post would carry a duplicate count. Enable with `params.webmentions_live = true`. Off by default: it is a third-party request on every page load, which is a real privacy and performance cost for a feature whose main value is already served statically. */}} {{- if site.Params.webmentions_live -}} {{- $target := .Permalink -}} {{- $known := 0 -}} {{/* How many the static render already accounts for, so the live number can be shown as a delta rather than a contradiction. */}} {{- $path := strings.Trim .RelPermalink "/" -}} {{- $slug := strings.ToLower (strings.Trim (strings.ReplaceRE `[^a-zA-Z0-9]+` "-" $path) "-") -}} {{- with index hugo.Data.webmentions $slug }}{{ $known = len . }}{{ end -}}

{{- end -}}
